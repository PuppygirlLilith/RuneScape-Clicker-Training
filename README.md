# RuneScape Clicker Training
**Plays a clicker sound when you've leveled up! Good doggy!**

Currently still just working my way through making this as a way to learn the API, I don't expect it to end up super complex. Very basic functionality exists, but I haven't been able to test it yet due to the cheat commands not working yet. I plan to eventually allow for customization of the reward message that is sent in the chat on level up, and if it's supported, potentially swap out the sounds from a small selection of other sounds. Still getting a feel for what the API is capable of.

[Inspired by this RuneLite plugin](<https://runelite.net/plugin-hub/show/clickertraining>)

Github Repo: https://github.com/PuppygirlLilith/RuneScape-Clicker-Training
